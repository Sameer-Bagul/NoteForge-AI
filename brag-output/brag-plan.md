# Brag Plan: NoteForge AI

## What is this app?
A production-ready, autonomous RAG pipeline that transforms YouTube videos into comprehensive study notes, interactive mind maps, and quizzes using a resilient Hybrid LLM Router.

## The angle
Enterprise-grade AI built for speed and resilience.
The video won't just say "it takes notes"—it will visually emphasize the heavy-duty architecture (Deterministic Chunking, LangGraph self-correction loops, and local fallback) working seamlessly behind a beautiful glassmorphic UI.

## Hook (first 2-3 seconds)
A Youtube URL is pasted into a sleek input field. It instantly shatters into dozens of timestamped chunks, visually demonstrating the "Deterministic Slicing" feature.

## Key moments (the middle)
- The LangGraph Loop: A visual representation of the Critic node rejecting a hallucination and looping back instantly.
- Hybrid Routing: Traffic visually splitting between Gemini (Cloud) and Ollama (Local) depending on the task.
- The Output: A stunning, formatted Bento-style PDF note document rendering.

## Outro / punchline
"Don't just summarize. Understand." followed by the NoteForge logo and GitHub link.

## User flow worth showing
1. User pastes a long YouTube playlist URL.
2. The UI shows processing: Extracting → Chunking → RAG.
3. The final structured Markdown/PDF note appears.

- Creative direction: High-performance, enterprise-grade AI architecture launch.
- Interpretation: Dramatic wipes, fast entrance animations that settle into comfortable reads. No chaotic flashes. It should feel like a serious, premium engineering tool.
